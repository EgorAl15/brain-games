# Brain Games

Проект консольных игр на Java + Gradle.

## Доступные игры
- **Greet**: простое приветствие.
- **Even**: проверка числа на чётность (ответьте "yes" или "no").
- **Calc**: математический калькулятор (решите пример с +, - или *).

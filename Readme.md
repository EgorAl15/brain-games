# Brain Games

Проект консольных игр на Java + Gradle.

## Доступные игры
1) Greet: простое приветствие.
2) Even: проверка числа на чётность (ответьте «yes» или «no»).
3) Calc: математический калькулятор (решите пример с +, - или *).
4) GCD: найдите наибольший общий делитель двух чисел (например, для 25 50 ответ — 25).
5) Progression: угадайте пропущенное число в арифметической прогрессии (в вопросе оно заменено на ..; например, в ряду 5 7 9 .. 13 нужно ответить 11).
